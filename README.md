## 📝 Descripción
Este repositorio contiene la práctica **U04-A2** para el módulo de **Entornos de Desarrollo**, en primero del grado superior **DAM**.
El objetivo principal es demostrar el dominio del flujo de trabajo con Git, la gestión de ramas y la integración profesional con el IDE **IntelliJ IDEA**.

## 🛠️ Tecnologías y Entorno
- **Lenguaje:** Java.
- **IDE:** IntelliJ IDEA.
- **Control de Versiones:** Git & GitHub.
- **Sistema Operativo:** Windows 11.

## 📂 Estructura del Proyecto
- `master`: Rama principal que contiene el código estable y refactorizado.
- `develop`: Rama de desarrollo donde se implementan nuevas funcionalidades y pruebas.

## ⚙️ Flujo de Trabajo 
He seguido un modelo de ramificación simple para cumplir con los requisitos académicos:
1. **Clonación local** del repositorio remoto.
2. **Commit inicial** con las clases base del proyecto Figuras.
3. **Refactorización** del código y segundo commit en la rama `master`.
4. **Desarrollo paralelo** en la rama `develop` para modificaciones específicas.
